## Ask

Do entity shortcut params (`hostNames`, `userNames`, `sourceIps`, `destIps`) in the inline tool schema meaningfully reduce token cost and tail behavior risk compared to a minimal `{ alertId, timeWindowHours }`-only schema?

## Our Findings

**Yes — entity shortcut params are worth keeping, and v5 is the best variant across every metric.**

The key discovery came from running 15-repetition evals (75 total runs per variant) with enough statistical power to separate signal from noise:

- At 15 reps, v5 beats legacy on every token metric: -16% mean (217k vs 258k), -14% median (83k vs 96k), -27% max (840k vs 1.1M), and -15% mean tool calls (5.3 vs 6.2).
- Groundedness reaches **0.90** — best across all variants.
- The entity shortcut params allow the model to skip entire `security.alerts` round-trips, which dominates the savings. Schema description overhead (~100 tokens/turn) is negligible by comparison.

**Lesson: schema size is not the dominant cost driver. Tool call efficiency is.** Entity params save the model from refetching data it already has, compounding across turns.

## What this PR does

Stacked on v4 (#269443). The Workflows step type is unchanged. This PR adds:

- Removes all v2 (api-driven) artifacts:
  - `alert_analysis_skill_api_driven.ts` and its test deleted
  - `evals_alert_analysis_api` Scout config set deleted
  - `alertAnalysisApiDrivenSkill` feature flag removed from `experimental_features.ts`
  - `register_skills.ts` collapsed from 3-way to 2-way flag (inline-api-tool vs legacy)

- `maxResults` hardcoded to 25; not model-controlled
- Adds `evals_alert_analysis_legacy` Scout config set for running v1 baseline evals
- 11 unit tests updated and passing

## Why entity shortcut params matter (the key insight)

Schema description text for 4 optional params costs ~100 tokens per turn. The payoff: when the model already has entity values from a prior `security.alerts` call, it can pass them directly and **skip an entire `security.alerts` round-trip** on the next turn. A `security.alerts` response carries full alert `_source` data — potentially 2,000–5,000 tokens that then accumulate in every subsequent turn's context. At 15 reps the effect is clear: v5 beats legacy on every token metric and cuts max tool calls from 21 → 15.
